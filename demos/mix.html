Mix

The effect animates a single CSS custom property, --proximity, from 0 far from the pointer to 1 near it. The page's own CSS does the rest: color-mix() blends each tile's colour, calc() works out its size, and a paused @keyframes animation is scrubbed through three shapes by setting its animation-delay from the value.

The effect only ever writes one number per tile, so attack and decay ease all three together.
